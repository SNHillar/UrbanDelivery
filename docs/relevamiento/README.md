# Relevamiento UrbanDelivery

Instrumentos anónimos (Google Forms) para validar el problema con consumidores y comercios.

## Por qué anónimo

En la localidad, varios actores prefieren no exponerse por WhatsApp o entrevista nominada. Los formularios permiten responder sin nombre ni teléfono. Mejor evidencia anónima documentada que cero respuestas.

## Cómo usarlo

1. Crear **dos** Google Forms (no uno solo).
2. Copiar las preguntas de:
   - [form-consumidores.md](form-consumidores.md)
   - [form-comerciantes.md](form-comerciantes.md)
3. En ambos: desactivar “recopilar correo”; no pedir nombre.
4. Difundir el link (grupos del pueblo, WhatsApp, QR). A comercios: mensaje corto + link.
5. Exportar respuestas (hoja de cálculo) y sintetizar en `docs/02-actualizacion.md` **sin datos personales**.

## Meta orientativa

- Consumidores: 8–15 respuestas (ya hay 3 entrevistas previas).
- Comercios: 3–5 respuestas (prioridad).

## Nota para el tutor

Método mixto: entrevistas exploratorias a consumidores + encuesta anónima por fricción de exposición. Limitación: menos profundidad narrativa; compensación: 1 campo abierto al final y, si aparece un comercio dispuesto, 5 minutos de charla opcional.
